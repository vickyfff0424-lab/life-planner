# 我的日程

一个使用 Electron、React、TypeScript 和 Vite 构建的 Windows 桌面日程与待办应用。界面为简体中文，任务仅以 JSON 文件保存在本机，不需要账号、云服务或 API key。

## 功能

- 添加、编辑、删除、完成和恢复待办
- 日期、时间、优先级、标签、描述和提醒
- 今天、即将到来、月历和已完成视图
- 按优先级、标签筛选；未来任务按日期分组
- Windows 系统通知及同一次提醒去重
- “今日回忆”日记：每日一条留言，可编辑、清空并显示最后保存时间
- 三年/五年同月同日历史对照，支持闰年 2 月 29 日
- 日历选中任意日期后，可查看和编辑该日留言
- 无边框桌面小组件：鼠标离开后可自动收缩到屏幕右侧
- 支持浮窗置顶、本机自定义背景图片和背景透明度调节
- 窗口失去焦点后才会延迟收缩，输入时不会突然消失
- 浮窗可拖动边缘自由缩放，并提供小、标准、大三种尺寸
- 最近七天日记入口，便于补写遗漏的记录
- 内置固定公历中国节日，并支持生日、纪念日等自定义日历标注
- 默认“本周计划”首页，按周一至周日安排任务并切换前后周
- 包含圣诞节、平安夜、情人节、母亲节、父亲节等常见生活节日
- 关闭窗口后驻留系统托盘，继续检查提醒
- 安全的 contextIsolation、preload 白名单 IPC，禁用 nodeIntegration
- JSON 临时文件原子写入及上一版本备份

## 环境要求

- Windows 10 或 Windows 11
- Node.js LTS（包含 npm）

## 安装与开发

```powershell
npm install
npm run dev
```

开发命令会同时启动 Vite 和 Electron。修改前端代码后页面会自动刷新。

## 测试

```powershell
npm run test
```

测试覆盖今天/即将到来的日期分类和任务完成状态切换。

## 正式构建

```powershell
npm run build
```

生成的网页资源位于 `dist/`，Electron 主进程资源位于 `dist-electron/`。

## 生成 Windows 安装包

```powershell
npm run dist
```

安装程序生成在 `release/` 目录，文件名类似 `我的日程-安装程序-1.0.0.exe`。

## 本地数据与隐私

任务保存在 Electron 的 `userData` 目录下，文件名为 `todos.json`；日记留言独立保存在 `journal.json`。Windows 上通常位于 `%APPDATA%/我的日程/`。写入前会分别生成 `.bak` 备份，数据结构也为后续本地导出预留了空间。应用不会收集、上传或同步任何数据。

关闭主窗口不会退出应用。要完全退出，请在 Windows 系统托盘中右键“我的日程”图标并选择“退出”。

## 桌面小组件

窗口顶部可以拖动浮窗，也可以拖动窗口边缘调整大小。点击右上角齿轮可设置小/标准/大尺寸、自动收缩、保持置顶、背景图片和透明度。自动收缩开启时，切换到其他窗口并等待约 2.5 秒后才会缩到屏幕右侧，输入期间不会收缩；把鼠标移到蓝色侧边标签上即可重新展开。背景图片只复制到本机 `userData` 目录。

月历中会显示元旦、劳动节、国庆节等固定公历节日。选中日期后点击“添加标注”，可以记录生日、纪念日或其他事项，并选择仅当年或每年重复。自定义标注独立保存在 `calendar-marks.json`。

应用默认打开“本周计划”，集中显示周一至周日。每天右上角的 `＋` 可以直接为该日添加任务；任务可在周视图中完成、编辑或删除，并可查看上一周和下一周。
